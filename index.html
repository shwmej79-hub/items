Supabase 클라우드 DB 연동 설정

Supabase 프로젝트 정보를 입력하시면 브라우저 로컬 저장소가 아닌 PostgreSQL 클라우드 데이터베이스에 모든 자산 데이터가 실시간으로 영구 저장됩니다.

Supabase 대시보드 -> Project Settings -> API -> Project URL
Supabase 대시보드 -> Project Settings -> API -> Project API keys -> anon (public)
테이블 생성이 필요하신가요?

프로젝트 루트 폴더에 준비된 supabase_schema.sql 파일 내용을 Supabase SQL Editor에 복사 후 실행하시면 테이블 및 보안 정책(RLS)이 1초 만에 구성됩니다.
