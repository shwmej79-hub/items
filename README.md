# 기업 고정자산 및 비품 관리대장 시스템

기업 및 기관에서 IT 기기(노트북, 모니터), 사무용 가구, 전자기기, 차량 등 모든 고정자산과 비품을 체계적으로 전산 관리할 수 있는 **웹 대시보드** 및 **엑셀 템플릿** 패키지입니다.

---

## 📁 제공 파일 구성

1. **`index.html`** (웹 대시보드)
   - 설치 없이 **더블클릭만으로 크롬/엣지 등 브라우저에서 즉시 실행**되는 단독 웹 애플리케이션
   - 신규 자산 등록, 수정, 삭제, 상세 조회
   - 다중 조건 검색 (코드, 자산명, 실사용자, 시리얼번호, 위치 등)
   - 카테고리 / 관리부서 / 상태별 필터링 및 다중 선택 일괄 삭제
   - KPI 통계 카드 (총 자산 수, 총 취득가액, 사용 가동률, 수리/유휴 건수)
   - Chart.js 기반 인터랙티브 시각화 차트 (부서별 자산 수량 분포, 카테고리별 취득금액)
   - **클릭 한 번으로 엑셀(.xlsx) 내보내기 & 엑셀 파일 불러오기(업로드)** 지원
   - 브라우저 로컬 스토리지(LocalStorage)에 실시간 자동 저장

2. **`create_excel.py`** (파이썬 엑셀 양식 생성 스크립트)
   - `openpyxl` 라이브러리를 활용하여 실무 서식, 천단위 콤마/원화 서식, 합계 자동 수식(`SUM`), 통계 요약 시트(`COUNTIF`, `SUMIF`), 드롭다운 선택 목록이 내장된 `고정자산관리대장_표준양식.xlsx` 파일 생성

3. **`README.md`** (본 설명서)

---

## 🚀 빠른 시작 가이드

### 방법 1: 웹 대시보드 바로 사용하기 (가장 추천!)
1. 파일 탐색기에서 **`index.html`** 파일을 더블클릭하여 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. 이미 9건의 실무 샘플 데이터(맥북, 모니터, 허먼밀러 의자, 법인차량 등)가 탑재되어 있어 기능을 바로 테스트해보실 수 있습니다.
3. 상단 우측의 **[신규 자산 등록]** 버튼을 눌러 새 비품을 등록합니다.
   - 자산관리코드는 [자동생성] 버튼을 눌러 카테고리 및 연도별로 번호를 자동 부여할 수 있습니다.
4. 상단 우측의 **[엑셀 내보내기]** 버튼을 누르면 대시보드에 등록된 모든 데이터가 정리된 `.xlsx` 파일로 즉시 다운로드됩니다.
5. 기존에 작성한 엑셀 파일이 있다면 **[엑셀 불러오기]** 버튼을 통해 한 번에 가져올 수도 있습니다.

---

### 방법 2: 파이썬으로 엑셀 파일 생성하기
파이썬 환경이 구축되어 있다면 아래 명령어로 수식과 드롭다운이 적용된 엑셀 파일을 생성할 수 있습니다:

```bash
# 필수 라이브러리 설치
pip install openpyxl

# 엑셀 파일 생성
python create_excel.py
```
실행 완료 시 `고정자산관리대장_표준양식.xlsx` 파일이 생성됩니다.

## 💡 유용한 팁
- **데이터 백업**: 브라우저 캐시를 지우더라도 보존될 수 있도록 정기적으로 **[엑셀 내보내기]**를 진행해 파일로 보관해 두시는 것을 권장합니다.
- **인쇄 및 PDF 저장**: 브라우저에서 `Ctrl + P`를 누르면 깔끔한 목록 형태로 출력하거나 PDF로 저장할 수 있습니다.
